### Коротко о проекте и причинах остановки

Этот проект я начала на основе макета, который, к сожалению, оказался не проработан для реализации. В нём отсутствовала логика ключевых интерфейсов и многие страницы, поэтому я приняла решение **не продолжать бессмысленную вёрстку "муляжа"**, а сосредоточиться на задачах с продуманным UX.

Основные проблемы, с которыми я столкнулась (мои заметки "на полях"):

1.  **Резина в слайдере не работает** — в макете не было заложено поведение для разных разрешений.
2.  **Grid в слайдере "глючит"** — пришлось использовать Flex, чтобы хоть как-то выстроить карточки.
3.  **Переключатели в слайдере (`CLOTHES`) не работают** — нет логики переключения, только заглушка.
4.  **Стили кнопок "на коленке"** — пример `// let active = document.querySelector('.catalog__button--active');Меняли стили css
      // active.style.color = 'black'` показывает, что я пыталась оживить хоть что-то, но это не системное решение.
5.  **Макет кривой** — центровка блоков "гуляет", пришлось выравнивать "костылём" (`left: 50%; transform: translateX(-53%);`).

### Выводы и что я вынесла из этого опыта

Этот проект — отличный пример того, **почему важно оценивать макет до начала вёрстки**. Теперь я всегда проверяю:

*   Наличие всех состояний элементов (слайдеры, кнопки, фильтры).
*   Логику переходов и наличие всех страниц (каталог, карточка товара).
*   Проработанность адаптива.
